# BattleArena - PUBG-type offline battle royale (Godot 4)

Tum + 11 bots ek arena me. Shrinking blue zone. Last one standing wins.
100% offline - koi server, login ya extra download nahi.

## Khelna
- Left thumb: move (joystick) | Right thumb: aim | FIRE button: shoot
- Blue zone ke andar raho, bahar HP katega
- Sabko harake #1 aao

## Build (sab free server par, phone me kuch nahi)
Repo me push karte hi Actions me `Build BattleArena APK` chalega.
`Artifacts > BattleArena-apk` download karke install karo.

Engine: Godot 4.3 (open source, MIT). Package: `com.srizvi.battlearena`.
